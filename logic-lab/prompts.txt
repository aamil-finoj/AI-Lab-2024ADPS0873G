PROMPTS USED WITH THE LLM  (Appendix)
======================================

Prompt 1 (Task 2 - generate the planner)
----------------------------------------
I want to implement a simple planning agent in Python.

Represent a state as a set of logical propositions.

Each action should contain:
- a name;
- positive preconditions;
- negative preconditions;
- positive effects;
- negative effects.

An action is applicable if all of its preconditions are satisfied by the
current state. When an action is applied:
1. remove its negative effects from the state;
2. add its positive effects to the state.

Use breadth-first search to find a sequence of actions that achieves a
specified goal.

The program should also:
- detect when no plan exists;
- print the resulting sequence of actions;
- print the states reached after each action.

Explain the implementation and identify any assumptions you make.

Domain: locations A, B, C with connections A<->B and B<->C. Robot and package
start at A; goal is At(Package,C). Actions: Move(x,y), PickUp(Package,loc),
Drop(Package,loc) with the preconditions and effects given in the lab sheet.

Prompt 2 (Task 3 - independent checker)
---------------------------------------
Write a separate validate_plan() function that re-executes a plan from the
initial state, checks every precondition at each step, and prints a trace.
It must not reuse the planner's search code.

Prompt 3 (Task 5 - LLM self-explanation)
----------------------------------------
For every action in the plan, identify its preconditions and show that those
preconditions are satisfied in the state in which the action is executed.

Prompt 4 (Task 7 - Prolog bridge)
---------------------------------
Write a small Python script that runs the planner, then asks SWI-Prolog
(planner.pl) whether each Move(x,y) in the plan satisfies valid_move(x,y).
